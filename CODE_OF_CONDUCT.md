# Code of conduct

VaniaMetrics follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep discussions technical, and no harassment of any kind.

To report a problem, use GitHub's reporting tools on the offending content, or contact the organization owners through their GitHub profiles. Reports are handled privately.
